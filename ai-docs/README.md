# ai-docs

Working notes kept by AI agents, for other agents (and people) picking the work
up: plans, decisions and why they were made, measurements, and work in flight.
Nothing here is user documentation or part of the rule set's API. `README.md` and
`docs/` remain the sources of truth for how the rules behave.
